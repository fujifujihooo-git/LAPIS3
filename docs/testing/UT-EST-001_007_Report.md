## 重要確認ポイントの詳細

### 1. 税計算の検証 (UT-EST-002, 005)

**テストシナリオ（UT-EST-005）:**
- 課税明細1: 15,000円
- 非課税明細1: 3,300円
- 課税明細2: 2,000円

**実行結果（ドキュメント生成情報からの抽出）:**
- **課税小計:** ¥17,000-
- **非課税小計:** ¥3,300-
- **消費税:** ¥1,700-  *(17000 * 0.1 = 1700)*
- **合計金額:** ¥22,000-

**結論:** `estimateItems` を正とし、各行の `is_taxable` フラグを基に厳密な再計算が正しく行われていることを確認しました。消費税が過剰に加算される誤実装（例: 3,000円になる）は発生しません。

### 2. 見積番号とファイル名の検証 (UT-EST-007, 008)

**テストシナリオ（案件番号設定時）:**
- 案件番号: `2026-00123`
- 結果: 見積番号は `EST-2026-00123` として印字・ファイル名へ設定される。

**テストシナリオ（案件番号未設定時）:**
- 案件番号: `null` または空文字
- 結果: 見積番号は `EST-NEW` として印字・ファイル名へ設定される。`EST-` のような不自然なフォーマットにはならないことを確認しました。
- 同時に、ファイル名に顧客名 `顧客/株式会社?テスト*` が渡された場合、`見積書_顧客_株式会社_テスト__EST-NEW.pdf` のようにサニタイズされることを確認しました。
