# 請求無効化（cancelled）ステータス管理・UI仕様書

作成日: 2026-08-04  
ステータス: 確定

---

## 1. 目的

請求書の無効化（論理削除）処理において、データの一貫性を損なわずに、UI表示および各種財務計算から該当データを正しく除外・分類する動作を定義する。

---

## 2. データ定義と更新処理

### 2.1. `deleteInvoice` 実行時のFirestore更新項目
`invoice_detail.html` で「無効化（取消）」ボタンをクリックした際、`invoices` コレクションの該当ドキュメントを以下のように更新する。

| フィールド | 設定値 | 備考 |
|---|---|---|
| `status` | `'cancelled'` | 取消状態を識別する値 |
| `balance` | `0` | 未収計算の誤判定を防ぐため、明示的に `0` とする |
| `last_updated` | `firebase.firestore.FieldValue.serverTimestamp()` | 更新日時を保存 |

---

## 3. 各画面でのUI動作仕様

### 3.1. 請求書一覧画面 (`invoice_list.html`)
- **デフォルト表示（残高ありのみ表示 ON）**:
  - `status === 'cancelled'` の請求書は **一覧に表示しない**（`balance` が `0` であるため自動的に除外される）。
- **ステータスフィルタ**:
  - ドロップダウンに `無効（取消）` を選択肢として追加する。
  - 値が `cancelled` の時、`status == 'cancelled'` に一致するデータのみを表示する。
- **バッジ表示**:
  - CSSクラス `.status-cancelled` を適用し、グレー色調のバッジとして「取消」と表示する。
  - スタイル定義: `background-color: #e5e7eb; color: #4b5563;`

### 3.2. 案件詳細画面 (`detail.html`) の関連請求テーブル
- テーブル内には履歴確認のため `status === 'cancelled'` のデータも行表示する。
- 表示行には `.cancelled-row` などのスタイルを適用してグレーアウト（または取り消し線）を施す。
- 案件サマリ（請求合計、入金合計、未回収合計）の**算出ロジックからは完全に除外**する。

---

## 4. 財務・財務サマリ集計ルール（他の財務集計含む）

LAPIS3内の他の集計機能（売上集計、未収金一覧など）における `cancelled` ステータスの扱い。

1.  **売上集計・各種財務レポート**:
    -   `status === 'cancelled'` の請求書データは **売上および請求額の集計に一切含めない**。
2.  **消込（入金）処理**:
    -   無効化された請求書に対する新規の消込処理は不可とする。
    -   すでに消込（入金充当）が行われていた請求書を無効化する場合、既存の消込履歴自体は参照用に残るが、新規で入金を充当することはできない。
