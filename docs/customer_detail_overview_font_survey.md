## 3. 現状の分析と視認性改善提案

### 課題分析
1. **サブ情報・バッジ類の視認性**: `8.5pt` 〜 `10pt` の要素（バッジ、管轄先、受任日、対応履歴本文など）がやや小さく、パッと見たときの読み取り負荷が高い。
2. **基本情報・特記事項の本文**: カルテで最も参照される基本情報テーブルの値（`12pt`）やメモ（`11pt`）を拡大することで、格段に見やすくなる。
3. **UDフォントの活用**: すでに `BIZ UDGothic` が設定されているため、フォントサイズのスケール調整（+1〜2pt）のみで非常に高い効果が期待できる。

### 💡 改善推奨案（Before / After）

| 領域・要素 | 現状 (Before) | 改善提案 (After) | 改善の狙い・効果 |
| :--- | :--- | :--- | :--- |
| **基本情報 テーブル値 (TD)** | `12pt` (顧客名は13pt) | **`13pt`** (顧客名は **`14pt`**) | カルテの最重要情報（住所、電話、代表者等）を一目で読み取れるようにする |
| **基本情報 テーブル見出し (TH)** | `11pt` | **`12pt`** | ラベルの視認性を高め、項目の区分けを明瞭にする |
| **メモ・特記事項** | `11pt` | **`12.5pt` 〜 `13pt`** | 重要な注意書きやメモを読みやすくする |
| **ミニテーブル見出し (TH)** | `10pt` | **`11pt`** | 許認可・案件の列タイトルを見やすくする |
| **ミニテーブル値 (TD)** | `11.5pt` | **`12.5pt`** | 許認可名、許可番号、金額等の数字の可読性アップ |
| **ステータスバッジ類** | `8.5pt` 〜 `9pt` | **`10pt` 〜 `10.5pt`** | 有効期限状態や案件進捗バッジの視認性を改善 |
| **対応履歴の件名・本文** | 件名 `11pt` / 本文 `9pt` | 件名 **`12pt`** / 本文 **`10.5pt`** | 直近のやり取りをスクロールせず快適に読めるようにする |
| **各パネルのアクションボタン** | `9.5pt` | **`11pt`** | 「✎ 編集」「一覧へ」ボタンの押しやすさ向上 |
